# STOP SCROLLING - Proyecto de Conciencia Digital 📱

Este proyecto fue desarrollado como parte de una iniciativa de concientización sobre el uso excesivo de dispositivos móviles en el entorno académico del **Colegio de Bachilleres Plantel 7**.

## 🎯 Objetivo
El objetivo principal es informar a la comunidad estudiantil sobre los riesgos de la dependencia digital y proporcionar una herramienta de autoevaluación (Test) para medir el nivel de impacto en su vida diaria.

## 📋 Cumplimiento de Requisitos
Este sitio web cumple con los siguientes criterios de evaluación:
1. **Acceso:** Liga funcional en GitHub Pages.
2. **Identidad:** Título corto y diseño atractivo.
3. **Contenido:** Problemática clara, historia de impacto y conclusión.
4. **Interactividad:** Test de 10 preguntas con resultados dinámicos.
5. **Fuentes:** Información basada en reportes de la OMS y Common Sense Media.
